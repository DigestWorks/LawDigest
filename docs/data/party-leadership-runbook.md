# 정당 지도부 갱신

정당 공식 자료에서 역할과 이름을 확인한 뒤, 검증 근거와 인물 정보를 한 트랜잭션에서 반영한다.

- `Party`의 지도부 이름과 `leadership_verified_on`, `leadership_source_url`을 함께 갱신한다.
- 확인일은 공식 자료에서 해당 직책을 확인할 수 있는 날짜다. 확인일로부터 30일이 지난 응답에서는 지도부 정보가 숨겨진다.
- 한 행의 출처 URL은 같은 행에서 표시하는 모든 역할을 뒷받침해야 한다. 출처에서 확인할 수 없는 역할에는 NULL을 사용한다.

## 운영 적용

1. `infra/db/migrations/20261103_add_party_leadership_verification.sql`의 두 컬럼이 있는지 읽기 전용으로 확인한다. 누락 시 handoff의 운영 DB 승인 절차로 마이그레이션을 준비한다.
2. 정당 공식 지도부 페이지·공지·일정에서 이름, 직책, 날짜를 확인한다. 직무대행이나 공동대표처럼 공식 직함이 다르면 현직 대표로 확정하기 전에 자료를 다시 확인한다.
3. 대상 정당의 ID와 기존 값, 교체할 필드, 확인일과 HTTPS 출처를 기록한다. 실행별 승인 뒤 기존 값이 같을 때만 새 값을 적용하고, 예상한 행 수를 확인한 다음 커밋한다.
4. `GET /v1/party/detail?party_id=…`와 정당 지도부 API에 같은 값이 나오는지 확인한다. 운영 프로필에서 이름, 확인일, 공식 출처 링크를 직접 확인한다.
