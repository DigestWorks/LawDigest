# 3차 집계 기준 검증

탐색의 분야 카드·목록·통계와 타임라인의 가결 집계를 제22대 READY 법안으로 맞췄다.

- 운영 재현에서 경제·세금 카드 6,331건과 통계 2,406건, 타임라인 가결 896건과 통계 828건을 확인했다.
- 분야 건수 API는 탐색 통계 쿼리를 공유한다. 목록에 같은 대수와 적재 상태를 적용하고, 요약이 없는 법안은 원문으로 연결한다.
- 타임라인은 탐색과 가결 쿼리를 공유한다. 이전 ‘처리법안’은 집계 기준에 맞춰 ‘위원회 심사 이상’으로 표시한다. 공포는 단계 수치다.
- 결과가 없으면 ‘결과 기록 없음’으로, 여러 가결 결과가 한 칸에 기록돼 있으면 ‘결과 확인 필요’로 표시한다. 0건이 아닌 작은 비율은 0.0%로 표시하지 않는다.
- 국회 ALLBILL의 법안 번호·ID와 본회의 의결일을 대조했다. 운영 후보 164건 중 161건은 공식 결과가 확인됐다. 실제 운영 반영은 별도 승인 후 검증한다.
- 격리 MySQL에서 이전 대수와 미검증 법안 제외, AI 요약이 없는 분야 법안 포함, 타임라인·통계의 가결 수치, 결과 기록과 미확인 결과 분리를 확인했다. 백엔드 58건, 웹 77건 및 서비스 빌드를 통과했다.
- 로컬 프로덕션 빌드와 읽기 전용 응답 중계로 375px 타임라인의 숫자·라벨과 제22대 분야 카드 표시를 확인했다. 운영 반영 확인과 의원·의석·프로필 지표는 이어서 진행한다.

## 의석과 대표발의 집계

운영 탐색의 정당 저장 의석 합계는 298석이었다. 정당 상세에서 더불어민주당은 170석이었지만 소속 의원 목록은 161명이었다. 현직 표시가 있는 운영 의원은 301명이며 국회 현직 명부는 299명이다. 국회 명부에 있는 14명의 운영 대수 값은 21이다. 따라서 의석·의원 목록은 현직 표시를 공유하고, 제22대 필터는 대표발의 법안에 적용한다.

- 의석도와 정당 상세가 현직 의원 집계를 공유한다. 무소속과 소속 미확인을 구분하고 선출 구분이 비어 있으면 별도로 표시한다.
- 의원 목록은 대표발의가 없는 현직 의원도 포함한다. 제22대 READY 법안의 고유 건수로 정렬하며, 동률은 이름·의원 ID 순으로 정렬한다.
- 격리 MySQL 59건을 통과했다. 재선 의원, 발의 0건, 소속과 선출 구분 미확인, 현직 제외, 과거 대수와 검증 대기 법안이 섞인 사례를 검사했다. 웹 린트, 테스트 77건과 프로덕션 빌드도 통과했다.
- 운영 명부를 읽기 전용으로 집계한 응답을 로컬 브라우저에 연결했다. 375px 의석도에서 301석과 무소속, 정당 상세에서 161석과 지역구 153석·비례대표 8석을 확인했다.
- 2026-11-03 [열린국회정보 국회의원 인적사항 API](https://open.assembly.go.kr/portal/openapi/nwvrqwxyaytdsfvhu)의 전체 299명을 다시 확인했다. 운영 현직 301명과 비교해 국회 명부에 이름과 코드가 모두 없던 이해민·권성동의 현직 상태만 정정했다. 김형연은 국회와 운영에서 현직임을 확인했다.
- 커밋 후 별도 읽기 전용 연결에서 현직 299명과 두 사람의 비현직 상태를 확인했다. 공개 운영 API의 국민의힘 현직 목록은 110명에서 109명으로 줄었고, 조국혁신당 12명에는 김형연이 포함됐다. 기존 두 의원의 상세 API와 운영 브라우저 프로필·발의 탭은 열렸다.
- 운영 국민의힘 프로필은 여전히 저장 의석수 108석과 현직 전체 299석을 표시한다. 소속 목록의 109명과 집계를 일치시키는 3차 코드를 배포한 뒤 두 값을 다시 확인한다. 이번 쓰기 실행기의 SHA-256은 `e4ac38d848bd442025c725d2d199e960fcde1c664e64aba0ee178b353b5c066c`다.


### 현직 의원 선출 구분과 대수 보완

현직 299명의 이름·소속 정당·선거구가 열린국회정보와 일치했다. 선출 구분 299건이 비어 있었고 현직 14명의 저장 대수는 21대였다. 새 명부를 다시 조회하고 기존 값이 검토 범위와 일치할 때만 한 트랜잭션에서 지역구 253명·비례대표 46명의 선출 구분과 14명의 제22대 대수를 반영했다.

- 커밋 뒤 별도 읽기 전용 연결에서 299명의 선출 구분과 대수를 확인했다. 공개 의원 상세 API에서도 이진숙의 지역구, 김형연의 비례대표를 확인했다. 실행 명세 해시는 `0311289ba179e1954aecf28e015bcce8779729c449833b2a0e76f0bf001335db`다.
- 명부 동기화가 공식 `ELECT_GBN_NM`을 전달하도록 수정했다. 해당 값이 빠진 재수집은 기존 선출 구분을 보존한다. Ruff, 관련 데이터 검사 24건, 격리 MySQL 9건, sdist·wheel을 통과했다. 수집 런타임 적용은 별도로 확인한다.

## 정당 프로필 (PROFILE-03, PROFILE-04, PROFILE-05, TRUST-11)

- 운영 사회민주당과 무소속 페이지의 메타 설명에 `undefined`가 있었고 무소속 로고가 `onull`을 요청했다. 운영 지도부 응답도 정당 공식 발표와 달랐다.
- 정당 상세와 메타 설명은 수집 의석을 기준으로 한 순위를 사용한다. 동률은 공동 순위이며, 무소속과 의석 0인 정당은 순위가 없다. 정당·의원 프로필의 로고 표시를 공유하며 누락이나 요청 실패 시 대체 표시로 전환한다.
- 지도부 API와 상세는 공식 출처와 30일 이내 확인일이 있는 항목을 노출한다. [운영 런북](../data/party-leadership-runbook.md)에 두 정당의 초기 갱신 후보와 작업 절차를 기록했다.
- 격리 MySQL에서 공동 순위, 무소속, 날짜가 없거나 오래된 지도부, 스키마 변경을 검증했다. 백엔드 60건, 웹 77건, 린트와 프로덕션 빌드가 통과했다.
- 375px 로컬 프로덕션 화면에서 다크 모드 무소속 대체 로고, 메타 설명, 공식 출처와 확인일이 있는 지도부를 확인했다. 2026-11-03 운영 MySQL에서 `ALGORITHM=INSTANT`로 확인일·출처 컬럼을 추가했다. 기존 정당 14개 행의 값이 보존됐고 신규 컬럼은 모두 NULL이었다. 국민의힘 지도부 한 행의 이름 네 개·확인일·공식 출처를 반영했다. 공개 상세와 지도부 API에는 새 이름이 나오고, 현재 운영 웹은 코드에 저장된 기존 명단을 표시한다. 3차 배포 뒤 화면을 재확인한다.

## AI 요약의 정당색 (W12)

사용자가 유지하기로 정한 단일 대표발의자 정당색을 공용 정당 팔레트와 연결했다. 기존 요약 전용 색상표에서 빠졌던 정당에는 해당 정당의 등록 색을 적용한다. 미등록 정당, 단일 소속이 없는 요약, 별도 리포트의 기본 강조는 중립 계열로 표시한다.

375px 로컬 프로덕션 빌드에서 법안 카드의 정당 데이터를 바꿔 기존 팔레트에 누락됐던 자유통일당과 미등록 정당을 확인했다. 밝은 화면과 다크 모드에서 각각 공용 파랑과 중립 회색을 사용했다. 중복 색상표 테스트를 제거한 뒤 웹 테스트 75건, 린트, 프로덕션 빌드가 통과했다.
