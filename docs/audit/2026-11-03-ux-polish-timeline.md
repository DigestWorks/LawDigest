# 타임라인 날짜별 기록 탐색 (W13)

타임라인에서 날짜와 단계, 위원회, 본회의 결과별로 기록을 훑고 각 법안을 직접 열 수 있다.

- 운영에서 3월 27일 위원회 2개, 3월 17일 공포 6건, 1월 29일 본회의 288건을 확인했다. 운영의 잘못된 페이지 크기 응답은 HTTP 500이었다.
- 캐러셀과 공유 모달을 인라인 목록으로 바꿨다. 같은 날짜에서도 각 위원회 목록이 독립적으로 펼쳐진다. 공포 목록의 각 행은 고유 법안 상세를 연다.
- 본회의 기록을 가결·부결·폐기·철회·미기록으로 묶고, 가능한 경우 찬성과 재석 수를 표시한다. 다음 날짜 요청의 오류는 기존 목록을 유지한 채 다시 시도할 수 있다.
- API는 페이지당 1~10개 날짜를 허용한다. 표결과 정당별 표결을 날짜별 일괄 조회하고, 위원회 법안도 한 번에 가져온다. 대표발의자나 정당 로고가 없는 법안도 기록에 포함한다.
- Redis의 새 페이지 캐시는 60초 TTL로 저장한다. 연결 장애 시 원래 조회 경로를 사용한다. 사용되지 않던 이전 캐시 스케줄러를 제거했다.
- 백엔드 테스트 67건·bootJar, 웹 테스트 75건·린트·프로덕션 빌드 통과. 격리 MySQL의 일괄 표결과 Redis JSON 읽기·만료를 검증했다.
- 운영 응답 표본을 사용하는 로컬 빌드에서 1440px 위원회 독립 펼치기, 375px 공포 링크 6개, 본회의 3→23건 펼치기, 이전 날짜 503 뒤 재시도를 확인했다.
- 운영 응답의 1월 29일 본회의 288건에는 결과 값이 없다. 화면은 미기록으로 표시한다. 실제 결과 보완과 운영 반영 검증은 W1과 함께 이어간다.

### 접수·본회의 이벤트 7,730건의 운영 실행 범위

국회 원자료와 운영 READY 법안이 일치하는 접수 7,121행과 본회의 609행을 동결했다. 고유 법안은 7,280건이다. 타임라인에 새 행을 추가하는 범위이며 기존 타임라인, 법안 상태·결과, 표결 수치 및 수집 기준점은 보존한다.

- 서버 `/tmp/lawdigest-w1-timeline-coverage/insert-verified-timeline-events.py` SHA-256은 `58df5448deb59c8b7d168c249eba166d0136e358043f7d0427ef4706791da4b3`이다. 읽기 전용 실행에서 두 단계의 대상 7,730행이 미등록 상태이고 법안의 번호·READY 상태와 접수일이 일치함을 확인했다.
- 격리 MySQL에서 기존 이벤트·공개 상태 변경 감지, 마지막 묶음 쓰기 실패 시 전체 롤백, 신규 7,730행의 정확한 대조, 기존 법안 결과와 범위 밖 이벤트 보존, 재실행 차단을 확인했다.
- 본회의 후보 609건 중 405건은 `Bill.bill_result`와 공식 의결 결과가 일치했고 204건은 `Bill.bill_result`가 NULL이었다. 이벤트에는 공식 결과를 저장한다. 현재 타임라인 API가 법안 행의 결과를 응답에 쓰므로, 날짜별 이벤트 결과를 사용자에게 표시하는 수정과 검증이 남아 있다.
- 승인 뒤 동시 수집 여부와 해시, 운영 읽기 전용 검증을 다시 확인하고 `--execute`를 한 번 실행한다. 반영 뒤 이벤트별 결과를 대조하고, 11월 2일 접수와 10월 28일 본회의를 운영에서 조회한다.

### 해당 날짜의 본회의 결과 표시

수정 후보의 타임라인 API는 법안의 본회의 이력을 묶어 조회하고 해당 날짜의 결과를 표시한다. 같은 날 결과가 충돌하면 결과와 표결을 비워 둔다. 결과가 없는 단일 날짜의 기존 기록은 법안 결과를 사용한다. 법안 ID로만 연결된 표결은 결과가 있는 날짜가 하나이고 법안 결과와 충돌하지 않는 경우에 표시한다. 예전 빈 이벤트와 여러 날짜의 결과가 섞인 경우에는 확인 가능한 결과와 표결을 구분한다.

- 격리 MySQL을 포함한 백엔드 검사에서 70건이 통과했다. Redis 연동 검사 1건은 건너뛰었고 `bootJar`가 성공했다.
- 격리 API와 브라우저에서 한 법안의 11월 3일 기록은 수정가결·찬성 150·재석 157, 11월 2일은 결과 기록 없음으로 확인했다. 데스크톱과 375px 다크 모드에서 확인했다. 운영 반영 뒤 실제 의결 표본으로 재검증한다.

본회의 이벤트 후보 609건 중 30건은 국회 합계에 표결 수치가 없는 철회였고, 6건은 승인된 161건 작업으로 표결과 정당별 기록을 이미 반영했다. 나머지 573건의 운영 `VoteRecord`와 `VoteParty`가 비어 있음을 읽기 전용으로 확인했다.

- 573건의 의안 ID·번호·의결일과 표결 합계를 확인했다. 결과는 원안가결 382건, 수정가결 190건, 부결 1건이며 범위는 3월 31일~10월 1일이다.

- 의안 2218858은 국회 합계에 총투표 177·찬성 167·반대 5·기권 5가 있었고, 의원별 API 재조회는 빈 응답이었다. 이 의안은 합계만 근거로 쓴다.
