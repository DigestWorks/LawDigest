# 7월 백필에서 빠진 발의자 관계 복구

현직 명부에 없던 발의자를 국회 역대 의원 자료와 대조한 뒤 첫 주 수집 후보 109건을 모두 검증했다.

- 2026년 7월 11~17일 최초 모의 실행에서 109건 중 7건이 제외됐다. 모두 공식 발의자 목록을 확보했지만, 현직 명부에서 이해민·권성동 의원 코드를 매칭하지 못했다.
- 국회의 역대 의원 통합 API로 이름·한자명·제22대 재직 이력을 대조했고, 두 코드가 모두 운영 공개 의원 API에 있음을 확인했다.
- 보완 코드를 적용한 격리 모의 실행: 109건 처리, 제외 0건. 별도로 발의일과 처리일 범위를 대조해 찾은 첫 주 법안 6건도 모두 처리했다. 6건 중 대안 관계 2개는 해당 법안의 존재를 확인한 뒤 별도 적재 대상으로 검토한다.
- 작업 중 DB 연결을 차단했다. 운영 법안·의원 명부·수집 기준점·스케줄을 변경하지 않았다.

공식 명단에서 현직 코드를 확정하지 못하면 [열린국회정보 역대 의원 통합 API](https://open.assembly.go.kr/portal/openapi/ALLNAMEMBER)를 조회한다. 명시된 대수와 이름·한자명이 모두 일치해야 한다. 응답 행 수가 선언된 건수와 다르거나 유효한 코드가 하나로 결정되지 않으면 기존처럼 법안을 재시도 대상으로 남긴다.

회귀 검증: Ruff 오류 검사 통과, 데이터 테스트 337건 통과·22건 건너뜀. 여론조사 PDF 검사 2건은 추적되지 않는 원본 PDF가 검증 워크트리에 없어 실패했다.
