# 모두의입법 계정 정책 검토 초안

공개 전 운영 주체, 문의 창구, 항목별 보유 기준을 확정하고 실제 탈퇴·파기 결과를 확인한다.

- 현재 코드에서 수집 항목과 사용 목적, 로그인 제공자, 탈퇴 시 삭제하는 데이터를 확인했다.
- 운영 주체명·공개 연락처·보유 기준은 모두 미정이다. 이 파일은 내부 검토용이며 웹 정책 경로에 연결하지 않는다.
- 탈퇴 실패 시 쿠키, 로그인 제공자의 인증 정보, 백업의 삭제 여부는 실계정과 운영 설정 확인이 필요하다.

## 개인정보 처리방침에 담을 내용

| 처리 항목 | 사용 목적과 범위 | 공개 전 확인 |
| --- | --- | --- |
| 로그인 제공자, 제공자 회원 식별자, 이름 또는 닉네임, 이메일, 프로필 이미지 URL | Google·카카오·네이버 로그인, 서비스 회원 식별, 마이페이지 표시 | 제공자별 필수·선택 항목, 실제 동의 화면, 회원 및 인증 정보 보유 기간 |
| 서비스 재발급 토큰, 로그인 제공자의 액세스·갱신 토큰, 인증 쿠키 및 세션 | 로그인 상태 유지, 토큰 갱신, 제공자 연결 해제 | 만료된 서버 기록의 파기, 제공자 토큰 행 삭제 여부, 기간과 접근 통제 |
| 스크랩한 법안, 팔로우한 의원·정당, 알림 내용 및 읽음 상태 | 저장 목록, 팔로잉 피드, 알림 제공 | 활동 데이터별 보유 기간과 탈퇴 시 삭제 검증 |
| 계정에 연결된 검색어, 브라우저 최근 검색어 | 검색 기록 기능. 브라우저의 최근 검색어는 로컬 저장소에서 최대 10개 유지 | 계정 검색어 기록의 현재 사용 경로, 서버 기록 보유 기간, 공유 기기·로그아웃 동작 |
| 질의응답의 질문·답변과 최근 대화 | 화면 세션 메모리에서 대화를 표시하고 질문·최근 질문·국회 근거를 Codex CLI gpt-6.1-terra에 전달해 답변 생성 | 외부 처리 주체·처리 지역·제공자 보유 기준, 실제 운영 로그·백업 범위 |
| 질의응답 요청 제한 식별값 | 프록시가 IP와 날짜를 HMAC으로 변환해 익명 요청 제한에 사용한다. 서비스 메모리의 일별 기록은 날짜 변경 시 초기화한다 | 운영 프록시 IP 설정과 접속 로그의 보유 기준 |
| 운영 접속 로그·백업 | 운영 설정에서 수집 여부와 목적을 확인한 뒤 기재 | 실제 항목, 수탁사·국외 이전 해당 여부, 보유·복구·파기 절차 |

검토 문안: “모두의입법은 소셜 로그인으로 서비스 계정을 확인하고, 회원이 저장하거나 팔로우한 항목과 알림을 제공하기 위해 위 정보를 처리합니다. 개인정보 열람·정정·삭제·처리정지 요청은 [운영 주체의 공개 문의 채널]에서 접수합니다. 항목별 처리 및 보유 기간, 파기 방법, 예외 보존 근거는 운영 기준을 확정한 뒤 표로 공개합니다.”

탈퇴 코드는 스크랩, 의원·정당 팔로우, 알림, 검색어, 회원·인증·로그인 제공자 토큰을 삭제하고 제공자 연결 해제를 요청한다. DB 작업과 연결 해제를 트랜잭션 안에서 시도하며, DB 커밋이 끝난 뒤 세션과 쿠키를 정리한다. 실제 제공자 연결 해제와 실패 후 로그인 상태, 백업의 파기 범위는 실계정·운영 설정으로 확인한다.

## 이용약관에 담을 내용

검토 문안: “모두의입법은 국회 공개 자료를 바탕으로 법안·의원·정당·입법 경과를 보여 줍니다. AI 요약은 법안 이해를 돕는 자료입니다. 법안 내용과 처리 상태의 공식 기록은 국회 의안정보시스템에서 확인할 수 있습니다. 소셜 로그인 회원은 법안 스크랩, 팔로우, 알림 기능을 사용할 수 있습니다.”

운영 주체와 문의 창구 확정 후 계정 사용·탈퇴 방법, 서비스 변경·중단 고지, 오류 정정·문의 절차, 시행일과 변경 이력을 작성한다. 실제 탈퇴 검증 후 화면의 삭제 범위 설명과 정책의 표현을 맞춘다. 공개 질의응답은 화면 세션 메모리에 대화를 보관하고 새로고침하면 초기화한다. 질문·최근 질문·국회 근거는 답변 생성기에 전달한다. Codex 실행은 ephemeral 모드와 임시 작업 디렉터리를 사용한다. 외부 처리와 운영 로그·백업의 보유 기준은 운영 주체가 확정한다.

- 회원·인증·활동 데이터: `User`, `AuthInfo`, `Token`, `OAuth2ClientToken`, `BillLike`, `CongressmanLike`, `PartyFollow`, `Notification`, `SearchKeyword` 엔티티.
