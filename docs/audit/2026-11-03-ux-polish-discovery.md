# 공개 화면 메타데이터와 사이트맵 (W15)

공개 페이지마다 제목, 설명과 정규 URL을 제공하고 사이트맵에서 공개 상세를 찾을 수 있게 했다.

- 운영 탐색·타임라인은 일반 제목과 홈 공유 정보를 사용했다. 운영 `robots.txt`와 `sitemap.xml`은 404였다. 사회민주당 프로필의 카카오 스크래퍼 응답은 공유 제목이 head 밖에 있었다.
- 탐색·타임라인·서비스 소개·검색·개인 영역의 메타데이터를 경로별로 설정했다. 개인 화면과 검색 결과는 색인에서 제외한다. 정규 URL은 기존 www 운영 호스트를 사용한다.
- Next.js의 기본 봇 목록을 유지하고 카카오·Telegram 공유 스크래퍼를 추가했다. 법안 조회 수는 화면을 실제로 연 브라우저에서 기록한다. 서버의 HTML 요청과 링크 미리보기는 조회를 발생시키지 않는다.
- 사이트맵 인덱스는 공개 법안·리포트·의원·정당 상세를 최대 2,000개씩 나눈다. 검증 완료되지 않은 법안과 그 리포트는 제외한다. 조회 실패 시 503을 반환해 빈 사이트맵을 정상으로 기록하지 않게 한다.
- 격리 MySQL에서 공개 리포트·법안 범위를 확인했다. 백엔드 테스트 67건과 bootJar, 웹 테스트 75건, 린트·프로덕션 빌드를 통과했다.
- 로컬 프로덕션에서 카카오의 법안과 Facebook의 정당 메타데이터가 head에 포함되는지 확인했다. 크롤러 HTML 요청 후 조회는 0건이었고, 실제 브라우저 상세는 1건을 기록했다. 분할 사이트맵과 robots, 범위를 벗어난 사이트맵 404를 검증했다.
- 운영 반영 뒤 카카오 공유 미리보기와 검색엔진 수집을 확인한다. 목록 전송량은 별도 변경에서 줄인다.
