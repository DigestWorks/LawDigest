# 공개 화면 메타데이터와 사이트맵 (W15)

공개 페이지마다 제목, 설명과 정규 URL을 제공하고 사이트맵에서 공개 상세를 찾을 수 있게 했다.

- 운영 탐색·타임라인은 일반 제목과 홈 공유 정보를 사용했다. 운영 `robots.txt`와 `sitemap.xml`은 404였다. 사회민주당 프로필의 카카오 스크래퍼 응답은 공유 제목이 head 밖에 있었다.
- 탐색·타임라인·서비스 소개·검색·개인 영역의 메타데이터를 경로별로 설정했다. 개인 화면과 검색 결과는 색인에서 제외한다. 정규 URL은 기존 www 운영 호스트를 사용한다.
- Next.js의 기본 봇 목록을 유지하고 카카오·Telegram 공유 스크래퍼를 추가했다. 법안 조회 수는 화면을 실제로 연 브라우저에서 기록한다. 서버의 HTML 요청과 링크 미리보기는 조회를 발생시키지 않는다.
- 사이트맵 인덱스는 공개 법안·리포트·의원·정당 상세를 최대 2,000개씩 나눈다. 검증 완료되지 않은 법안과 그 리포트는 제외한다. 조회 실패 시 503을 반환해 빈 사이트맵을 정상으로 기록하지 않게 한다.
- 격리 MySQL에서 공개 리포트·법안 범위를 확인했다. 백엔드 테스트 67건과 bootJar, 웹 테스트 75건, 린트·프로덕션 빌드를 통과했다.
- 로컬 프로덕션에서 카카오의 법안과 Facebook의 정당 메타데이터가 head에 포함되는지 확인했다. 크롤러 HTML 요청 후 조회는 0건이었고, 실제 브라우저 상세는 1건을 기록했다. 분할 사이트맵과 robots, 범위를 벗어난 사이트맵 404를 검증했다.
- 운영 반영 뒤 카카오 공유 미리보기와 검색엔진 수집을 확인한다. 목록 전송량은 별도 변경에서 줄인다.

## 탐색 분야 결과 (W16)

분야를 선택하면 전용 결과 페이지가 열리고, 분류 값이 없는 법안은 미분류 목록에서 볼 수 있다.

- 운영의 375px 화면에서 분야를 눌렀을 때 결과 제목은 1,329px 지점에 있었다. 변경 후 로컬 프로덕션 빌드에서 키보드 Enter로 분야를 열면 제목이 149px 지점에 표시됐다. 전체 분야 링크, 브라우저 뒤로 가기, 어두운 테마의 미분류 목록과 가로 넘침 여부를 확인했다.
- 분야 경로를 사이트맵에 추가했다. 일반 브라우저와 카카오 스크래퍼 요청 모두 유효한 분야에는 HTTP 200, 잘못된 분야에는 HTTP 404를 받았다.
- 목록과 통계의 미분류 기준을 통일했다. 기존 `unknown`, NULL, 빈 문자열을 포함한다. 운영 공개 통계에서 구한 미분류 4,751건과 미분류 법안 표본을 로컬 화면 검증에 사용했다.
- 격리 MySQL 및 Redis를 사용한 백엔드 테스트 67건과 bootJar, 웹 테스트 75건, 린트와 프로덕션 빌드가 통과했다. 운영 화면은 배포 후 다시 확인한다.

## 법안 목록 전송량 (JOURNEY-05)

법안 카드의 기본 전송량을 줄이고, 원문 제안이유와 전체 발의자 명단은 열 때 가져온다.

- 운영 API와 웹 프록시 모두 법안 3건에 38,150바이트를 압축 없이 반환했다.
- 피드 시간순·인기, 검색, 분야, 의원·정당 목록은 `compact=true`를 지원한다. 경량 응답은 발의자 수와 원문 보유 여부를 제공한다. AI 요약, 대표발의자, 스크랩 상태, 인기 지표와 페이지 정보는 유지한다. 기존 목록과 상세는 같은 필드를 반환한다.
- 격리 MySQL에 운영 공개 텍스트 표본을 넣고 같은 3건을 비교했다. 비압축 기존 형식 40,206바이트, 비압축 경량 형식 24,023바이트, gzip 기존 형식 8,988바이트, gzip 경량 형식 7,493바이트였다. API와 Next 웹 프록시에서 gzip 응답을 풀어 각각 비압축 JSON과 대조했다.
- 375px 로컬 프로덕션 화면에서 AI 요약 펼치기, 요약이 없는 분야 법안의 원문 열기·접기, 피드 마지막 페이지를 확인했다. 격리 환경의 상세 API가 HTTP 500을 반환하도록 한 뒤 발의자 팝오버의 오류와 재시도를 확인했다. API 복구 후 팝오버를 다시 열 필요 없이 발의자 16명이 표시됐다.
- 격리 MySQL 및 Redis를 사용한 백엔드 테스트 68건과 bootJar, 웹 테스트 75건, 린트와 프로덕션 빌드가 통과했다. 운영 전송량은 배포 후 측정한다.

## 모바일 하단 내비와 검색 (W11)

360px 화면의 하단 내비를 화면 안에 두고, 두 테마에서 탭과 검색 버튼을 읽고 조작할 수 있게 했다.

- 운영 다크 모드 360px에서 하단 내비 왼쪽 끝은 -7px, 검색 버튼 오른쪽 끝은 367px였다. 로컬 프로덕션 빌드에서는 양쪽 테마 모두 16px와 344px였다. 스크롤로 축소된 탭 4개와 검색 버튼은 각각 44×44px였다.
- 테마별 내비 배경, 활성 표시, 글자와 포커스 색을 적용했다. 배경이 가장 어둡거나 밝은 조건을 사용한 계산에서 활성·비활성 라벨 4개 조합의 대비가 5.73:1 이상이었다. [WCAG 2.2 텍스트 대비 기준](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)
- 360px에서 Enter와 Space로 테마를 전환하고, 키보드로 탐색 탭을 선택했다. 검색 대화상자는 다크 배경에서 내비 위에 열렸다. Esc로 닫으면 검색 버튼으로 복귀해 2px 포커스 표시가 나타났다. 1024px에서는 데스크톱 내비가 표시됐다.
- 알림·테마·뒤로·계정 설정·맨 위로·알림 닫기에 이름을 붙였다. 비로그인 알림을 Enter로 열고 닫는 동안 URL이 유지됐다. 스낵바와 맨 위로 버튼은 모바일 내비 높이와 하단 안전 영역을 공유한다. 로컬에서 두 요소가 내비 위에 표시되고 맨 위로 이동 후 스크롤이 0에 도달했다.
- 웹 테스트 75건과 린트·프로덕션 빌드가 통과했다. 물리 iPhone의 안전 영역과 실제 계정이 필요한 회원탈퇴 모달은 운영 검증에 남겼다.

## 글자 대비와 페이지 제목 (W11)

페이지·카드·요약의 제목 수준을 구분하고, 법안의 날짜·발의자·수치·미도달 단계에는 읽을 수 있는 보조색을 적용했다.

- 운영 공개 페이지 7개에는 `h1`이 없었다. 표본 법안 상세에는 `h4`가 374개 있었다. 로컬 프로덕션 HTML 13개 경로에서 `h1`과 주 콘텐츠 영역을 각각 한 개 확인했다. 표본 법안 상세는 빈 제목과 메타데이터 제목을 제거했다.
- 피드는 페이지·법안·요약을 `h1`·`h2`·`h3`으로 표시한다. 검색은 법안 절 아래에 카드 제목과 요약을 한 단계씩 둔다. 브라우저 접근성 트리에서 로그인·탐색·타임라인 제목과 피드·검색·상세 구조를 확인했다.
- 보조 글자는 라이트에서 #666666, 다크에서 #B3B3B3을 사용한다. 대표 배경 대비는 흰색 5.74:1, 다크 패널 7.95:1이었다. 법안 카드의 상세 버튼은 라이트 15.96:1, 다크 13.28:1이었다. 정당명 글자는 본문 색을 사용하고 정당색은 의원 이미지 테두리에 표시한다. [WCAG 2.2 텍스트 대비 기준](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)
- 375px 상세 화면에서 현재 위원회 심사 단계와 미도달 공포 단계의 글자·번호 테두리를 두 테마로 확인했다. 스크랩 버튼을 Enter로 누르면 비로그인 안내가 표시됐다.
- 웹 테스트 76건, 린트, 프로덕션 빌드가 통과했다. 회원 화면의 로그인 후 데이터는 실제 계정 검증에 남겼다.

## 탐색 아이콘과 알림 메뉴 (W11)

탐색 아이콘을 SVG로 바꾸고 알림과 정당 의원 목록을 키보드로 조작할 수 있게 했다.

- 운영 탐색 HTML에는 Material Symbols 스타일시트와 `tag`, `account_balance`, `monitoring` 문자열이 있었다. 로컬 프로덕션의 홈·탐색·미분류 경로에서 스타일시트와 리가처 마크업이 빠진 것을 확인했다.
- 데스크톱에서 분야 카드 18개, 사이드바 탭 3개, 통계 카드 제목 7개의 SVG를 확인했다. 탭의 접근성 이름은 분야·국회·통계였다. 375px 다크 화면에서 미분류 분야로 이동했고 가로 넘침이 없었다.
- 탐색의 정당 링크를 통해 프로필을 열고 Enter로 9번째 의원을 표시한 뒤 Space로 접었다. 접근성 상태는 펼치기 전·후·접은 뒤 각각 false·true·false였다. 운영 정당 직접 주소는 현행 프로필을 불러왔다. 이번 로컬 빌드의 직접 주소에서는 의원 목록이 로딩 상태에 머물러, 수정본의 직접 주소 재검증을 남겼다.
- 다크 알림의 최초 응답에서 빈 이미지 자리표시자로 인해 오류가 발생했다. 날짜별 그룹을 응답에서 바로 계산해 해결했다. 격리 알림 표본에서 전체·개별 메뉴를 Enter로 열고 Esc로 닫았다.
- 웹 테스트 77건, 린트, 프로덕션 빌드가 통과했다. 실제 계정의 알림 데이터와 읽음·삭제 동작은 운영 검증에 남겼다.
