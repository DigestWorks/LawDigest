# 인기 법안의 최근 7일 집계 (FEED-17, TRUST-15)

최근 168시간 조회수와 스크랩 수의 합계 순으로 제22대 READY 법안을 표시한다.

- 운영 응답에서 2026-07-09부터 2024-09-30까지 발의일 역순을 확인했다. 이전 Redis 큐는 시각을 기록하지 않았으며 법안 상세 정보 조회에서 인기 순서가 사라졌다.
- 조회수는 법안의 누적 수와 UTC 초 단위 집계를 한 트랜잭션에서 증가시킨다. 스크랩은 생성일이 기간 안에 있고 현재 유지 중인 행을 센다. 같은 점수는 발의일과 법안 ID로 정렬한다.
- 탭 이름은 ‘인기’로 표시한다. 집계 기간과 카드별 조회·스크랩 수를 보여 주며, 집계 시작 전 조회나 기간 밖 활동은 점수에 포함하지 않는다.
- 운영 `Bill.viewCount`와 `BillLike.created_date`를 읽기 전용으로 확인했다. 집계 테이블에는 법안 ID, 시각, 합계만 저장한다.
- 격리 MySQL에서 범위 밖 활동 제외, 스크랩 삭제와 순위 변경, 응답 순서, 12개 동시 조회의 누적·기간 집계를 검증했다. 백엔드 63건과 bootJar, 웹 77건·린트·프로덕션 빌드가 통과했다.
- 375px 화면과 1440px 다크 모드에서 기준 문구, 카드별 건수와 선택 상태를 확인했다. 로컬 검증은 운영 법안 카드 형태를 사용한 별도 집계 표본으로 실행했다.

## 운영 적용

2026-11-03에 `infra/db/migrations/20261103_create_bill_view_activity.sql`을 운영에 사전 적용했다. 적용 직후 외래 키와 빈 테이블 상태를 확인했다. 3차 배포 뒤 운영 웹에서 조회를 기록한다. 운영 웹에서 조회 후 누적 조회와 인기 카드가 함께 갱신되는지 확인한다. 일주일이 지난 조회 기록은 집계에 쓰이지 않으며, 보관과 정리 주기는 운영 작업에서 설정한다.
