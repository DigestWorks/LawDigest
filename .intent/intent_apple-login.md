# Apple로 로그인 추가

## 개발 목표와 의도

요청: "모두의입법에 Apple로 로그인을 구현하자."

지금 로그인 화면에는 카카오톡, 구글, 네이버 버튼만 있습니다. 세 서비스 계정이 없거나 쓰고 싶지 않은 iPhone·Mac 사용자는 가입할 방법이 없습니다. Apple 계정으로도 가입하고 로그인할 수 있게 하고, 탈퇴할 때는 다른 소셜 로그인처럼 Apple 쪽 연결도 끊기게 합니다.

Apple Developer 콘솔 값(Services ID, Team ID, Key ID, `.p8` 키)은 아직 없습니다. 그래서 이번 변경은 그 값을 서버에 넣는 순간 동작하는 코드를 만듭니다. 값을 넣기 전에는 Apple 버튼이 보이지 않고 서버도 정상 기동해야 합니다.

## 기능 목록

| 기능 | 설명 | 왜 필요한가 |
|---|---|---|
| Apple로 계속하기 버튼 | 로그인 화면의 소셜 로그인 버튼 목록 맨 아래에 Apple 로고와 "Apple로 계속하기" 버튼이 생깁니다. 누르면 Apple 로그인 화면으로 이동합니다. | 카카오·구글·네이버 계정이 없는 사용자가 가입할 수 없습니다. |
| Apple 계정 가입·로그인 | Apple 인증을 마치면 다른 소셜 로그인과 같이 로그인된 상태로 원래 보던 화면에 돌아옵니다. 처음 로그인하면 계정이 새로 만들어집니다. | 버튼만 있고 로그인이 안 되면 기능이 아닙니다. |
| 이름 저장 | 첫 가입 때 Apple이 알려 준 이름을 저장합니다. 이름을 받지 못하면 이메일의 @ 앞부분을 이름으로 씁니다. | 계정의 이름 칸은 비워 둘 수 없고, Apple은 이름을 첫 로그인 때 한 번만 보냅니다. |
| 탈퇴 시 Apple 연결 해제 | 마이페이지에서 탈퇴하면 Apple 계정 설정의 "Apple로 로그인" 목록에서 모두의입법이 사라집니다. | 연결을 끊지 않으면 다시 가입할 때 Apple이 이름을 보내지 않고, 다른 소셜 로그인과 동작이 달라집니다. |
| 설정 전 숨김 | Apple 값을 서버에 넣고 웹 설정을 켜기 전까지 버튼이 보이지 않습니다. | 값이 없는 상태에서 버튼을 보이면 누르는 사람마다 Apple 오류 화면을 봅니다. |

## 개발 목표

- 버튼: Apple 설정을 켠 테스트 웹 로그인 화면에 "Apple로 계속하기" 버튼이 보이고, 설정을 끈 운영 웹에는 보이지 않습니다.
- 가입: 테스트 웹에서 Apple 계정으로 로그인하면 마이페이지에 Apple 이름이나 이메일 앞부분이 보입니다.
- 탈퇴: 그 계정으로 탈퇴하면 Apple 계정 설정의 "Apple로 로그인" 목록에서 모두의입법이 사라집니다.
- 기동: Apple 값이 없는 서버도 기존과 같이 기동하고, 카카오·구글·네이버 로그인이 그대로 동작합니다.
- 자동 검사: 백엔드 `./gradlew test`와 웹 `npm run lint`, `npm test`가 통과합니다.

## 범위 밖과 제약

- iOS 앱은 없으므로 웹 로그인만 다룹니다.
- 같은 이메일로 이미 카카오 등으로 가입한 계정과 합치지 않습니다. Apple 계정은 별도 계정이 됩니다.
- Apple은 HTTPS 도메인 반환 주소만 받습니다. 로컬(`localhost`)에서는 끝까지 로그인할 수 없고 `test.api.lawdigest.kr`에서 확인합니다.
- Apple Developer 콘솔 설정과 서버 `.env` 입력은 사용자가 합니다. 이번 변경은 그 절차를 문서로 남깁니다.

## 열린 질문

- 운영 DB의 `auth_info.provider` 컬럼이 MySQL `ENUM('KAKAO','NAVER','GOOGLE')`이면 `APPLE` 저장이 실패합니다. 운영 DB 조회 권한이 막혀 확인하지 못했습니다. 설정 문서에 확인 쿼리와 변경 SQL을 적고, 사용자가 Apple 값을 넣기 전에 확인합니다.
