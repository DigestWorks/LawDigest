법안 피드에 제22대, 제21대, 전체(두 대수) 필터를 표시한다. 제22대를 기본값으로 사용하고 대수 선택은 URL, 페이지네이션, 서버 사전 조회에 반영한다. 제21대의 공개 대상 법안은 원문 제안이유와 원제목으로도 열 수 있다. HOT은 제22대의 최근 활동을 기준으로 제공한다. 목록과 공유 미리보기는 처리 결과를 우선 표시하며, 지난 대수는 카드에서 확인할 수 있다. 대수를 생략하는 기존 API 요청은 기존 조회 범위를 유지한다.
