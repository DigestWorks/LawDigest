# 모달 없는 제자리 확장 검색과 결과 전환

## 개발 목표와 의도

요청: "검색 진입/검색 로딩/검색 결과 표출이 자연스럽고 부드러운 애니메이션으로 진행되도록 하자." 사용자는 검색 모달을 쓰지 않기를 원한다. 지금의 중앙 대화상자는 사용자의 의도가 아니었다.

지금은 헤더 아이콘이나 모바일 무지개 버튼을 누르면 화면 가운데에 대화상자가 뜨고 검은 반투명 막이 화면을 덮는다. 검색어를 내면 대화상자가 사라지고 회색 상자 스켈레톤이 나온 뒤, 결과가 피드용 대형 법안 카드로 채워진다. 2026-11-08 운영 화면에서 '주택'을 검색하면 첫 화면에 법안이 한 건만 보였다.

이번 변경은 검색창을 누른 버튼 자리에서 펼친다. 모바일은 원래 디자인처럼 하단 내비 안에서 무지개 검색 바가 펼쳐지고, 데스크톱은 헤더 검색 아이콘이 헤더 안에서 검색창으로 펼쳐진다. 검색창은 결과 화면에서도 같은 자리에 남고, 그 아래 내용만 로딩과 결과로 바뀐다.

## 기능 목록

| 기능 | 설명 | 왜 필요한가 |
|---|---|---|
| 검색 대화상자 제거 | 화면 가운데 뜨는 검색 상자와 검은 막이 없어진다. | 사용자가 원하지 않은 방식이고, 누른 버튼과 열린 화면의 관계가 보이지 않는다. |
| 모바일 하단 내비 확장 검색 | 무지개 버튼을 누르면 탭 바는 현재 탭 아이콘 하나로 줄고, 검색 바가 탭 바 자리까지 펼쳐진다. 위로 최근 검색어와 지금 뜨는 키워드 말풍선이 차례로 떠오른다. 키보드가 열리면 검색 바가 키보드 위로 올라간다. | 원래 모바일 검색의 대표 디자인이었고, 엄지가 닿는 자리에서 검색을 시작할 수 있다. |
| 데스크톱 헤더 확장 검색 | 헤더 검색 아이콘을 누르거나 `/`, ⌘K를 누르면 활성 탭의 무지개 테두리가 그대로 늘어나 검색창이 되고, 나머지 탭은 사라진다. 바로 아래에 최근 검색어, 지금 뜨는 키워드, 법안에 질문하기가 펼쳐진다. 바깥을 누르거나 Esc를 누르면 접힌다. | 헤더 안에서 열리므로 화면을 가리지 않고, 페이지를 떠나지 않은 채 검색을 시작한다. |
| 상단 탭 인디케이터 이동 | 데스크톱 상단 탭을 누르면 무지개 테두리가 누른 탭으로 미끄러져 간다. 다음 화면을 불러오기 전에 바로 움직인다. | 지금은 테두리가 이전 탭에서 사라지고 다음 화면이 뜬 뒤에야 새 탭에 나타나, 무엇을 눌렀는지 늦게 보인다. |
| 검색 중 표시 | 검색어를 내면 검색창 무지개 테두리가 빠르게 돌고 추천 목록은 접힌다. 결과가 도착하면 회전이 멈춘다. | 지금은 제출 직후 검색창이 사라져, 검색이 진행 중인지 알 수 없다. |
| 결과 화면에서 유지되는 검색창 | 결과 화면에서도 헤더(데스크톱)나 하단 바(모바일)의 검색창이 펼쳐진 채 검색어를 보여 주고, 바로 고쳐 다시 검색할 수 있다. 결과 본문 위의 별도 검색 버튼은 없어진다. | 검색창이 단계마다 다른 자리에 있으면 흐름이 끊긴다. |
| 결과 모양의 로딩 화면 | 로딩 화면이 결과와 같은 배치(유형 탭, 결과 줄)로 나온다. | 범용 스켈레톤이 결과로 바뀔 때 배치가 통째로 바뀌어 화면이 튄다. |
| 결과 등장 전환 | 결과 줄이 위에서부터 차례로 짧게 떠오른다. 유형 탭(전체·법안·의원·정당)의 검은 선택 표시는 누른 탭으로 미끄러져 간다. | 결과가 한 번에 바뀌면 무엇이 새로 나왔는지, 어느 탭으로 바뀌었는지 보이지 않는다. |
| 한 줄 법안 결과 | 법안 결과를 한 묶음(쉬운 제목, 정식 법안명, 처리 단계, 발의일, 대표발의자)으로 보여 주고, 검색어와 일치하는 글자를 옅은 파란색으로 표시한다. | 피드 카드를 그대로 쓰면 첫 화면에 한두 건만 보여 찾는 법안을 고르기 어렵다. |

## 개발 목표

- 어느 화면에서도 검색을 열 때 중앙 대화상자와 검은 막이 나오지 않는다.
- 모바일 375px에서 무지개 버튼을 누르면 하단 내비 안에서 검색 바가 펼쳐지고, 말풍선에 실제 최근 검색어와 인기 키워드가 보인다.
- 데스크톱 1280px에서 헤더 아이콘, `/`, ⌘K로 헤더 안 검색창이 펼쳐지고, 검색 후 결과 화면에서도 같은 자리에 검색어가 남아 있다.
- '주택' 검색 결과 첫 화면(1280×820)에 법안 5건 이상이 보이고, 일치하는 글자가 표시된다.
- 운영체제의 '동작 줄이기'를 켜면 회전과 이동 전환 없이 짧은 페이드만 남는다.

## 범위 밖과 제약

- 입력하는 동안 결과를 미리 보여 주는 자동 완성은 하지 않는다.
- 피드·탐색·팔로잉의 법안 카드와 공용 대화상자 컴포넌트는 바꾸지 않는다.
- 결과 화면에 기준일·출처 같은 안내 문구를 넣지 않는다.
- 원래 디자인의 고정 예시 질문 말풍선 대신 실제 최근 검색어와 인기 키워드를 쓴다.

## 열린 질문

- 법안 결과를 한 묶음 줄로 바꾸는 것은 결과 구성 변경이다. 피드 카드를 원하면 법안 결과만 기존 카드로 되돌리고 등장 전환은 그대로 둔다.
