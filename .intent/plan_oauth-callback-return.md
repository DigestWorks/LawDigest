# 로그인 복귀 구현

1. 내부 복귀 주소 검증과 OAuth 시작 주소 생성 helper를 추가한다.
2. 로그인에 shadcn 알림과 기존 제공자 버튼을 연결한다. 세 콜백을 공통 클라이언트 컴포넌트로 바꾼다.
3. 기존 로그인 진입점에 returnTo를 붙이고 콜백에서 replace한다.
4. 복귀 주소 검증과 콜백 오류·정상 세션 분기를 집중 검사한다. 배포 후 실제 운영 OAuth 취소와 팔로잉 로그인 진입을 확인한다.
5. 실제 계정의 인증 성공과 제공자 화면의 취소는 사용자 로그인 이후 확인한다.

운영 확인에서 취소 응답의 returnTo 쿼리가 재인코딩됐다. 실패 handler는 기존 쿼리를 보존하고 새 오류 값만 인코딩한다. 기존 원점 제한과 쿼리 보존 회귀 검사를 실행한 뒤 취소·뒤로 가기를 다시 확인한다.
