# 이용약관과 개인정보 처리방침 공개

## 개발 목표와 의도

사용자는 "모두의입법에 개인정보처리방침과 사용자 약관 등을 구성하자"고 요청했다. 지금 모두의입법은 카카오·구글·네이버 로그인으로 이메일, 이름, 프로필 이미지를 받고 있다. 그런데 사이트 어디에도 개인정보 처리방침과 이용약관이 없다. 로그인 화면에도 버튼 세 개만 있어서, 이용자는 무엇이 수집되고 언제 지워지는지 알 수 없다. 개인정보 보호법 제30조는 처리방침을 홈페이지에 계속 게재하라고 정하고 있다. 이번 변경으로 두 문서를 공개 페이지로 만들고, 모든 화면 하단과 로그인 화면에서 이 페이지로 갈 수 있게 한다.

## 기능 목록

| 기능 | 설명 | 왜 필요한가 |
|---|---|---|
| 개인정보 처리방침 페이지 | `/privacy`에서 수집 항목, 목적, 보유 기간, 위탁, 국외 이전, 쿠키, 권리 행사 방법, 보호책임자 연락처를 목차와 함께 보여 준다. | 법정 공개 의무다. 이 페이지가 없으면 이용자는 자기 정보가 어디로 가는지 확인할 수 없다. |
| 이용약관 페이지 | `/terms`에서 가입 조건, 탈퇴, 금지 행위, AI 요약과 질의응답의 한계, 국회 공개 자료 출처, 책임 범위를 조항별로 보여 준다. | 이용 계약의 내용을 정해 두지 않으면 분쟁이 생겼을 때 기준이 없다. |
| 하단 링크 | 모든 화면 하단의 서비스 정보 영역에 "이용약관"과 굵게 표시한 "개인정보 처리방침"을 추가한다. | 처리방침은 다른 고지와 구분되게, 계속 게재해야 한다. |
| 로그인 화면 안내 | 로그인 버튼 아래에 "시작하면 이용약관에 동의하게 된다", "만 14세 미만은 가입할 수 없다"는 안내와 두 문서 링크를 보여 준다. | 가입 직전에 약관을 알리지 않으면 약관이 계약 내용이 되기 어렵다. 14세 미만 정보를 받으려면 법정대리인 동의 절차가 필요하므로 가입을 제한한다. |
| 사이트맵 등록 | 두 페이지를 사이트맵에 넣는다. | 검색엔진에서 처리방침을 찾을 수 있게 한다. |

## 개발 목표

- 처리방침 공개: `https://lawdigest.kr/privacy`에서 제30조 제1항과 시행령 제31조 제1항의 항목이 모두 보인다.
- 약관 공개: `/terms`에서 시행일 2026년 11월 8일과 조항 목차가 보인다.
- 하단 링크: 피드, 마이페이지, 로그인 화면 하단에서 두 문서로 이동할 수 있고, "개인정보 처리방침"이 굵게 보인다.
- 로그인 안내: `/login`에서 버튼 아래에 동의 안내와 만 14세 안내가 보인다.
- 실제 처리와 일치: 문서의 수집 항목과 보유 기간이 코드의 실제 동작(탈퇴 시 삭제 범위, 질의응답 질문 미저장)과 같다.

## 범위 밖과 제약

- 체크박스 동의, 동의 시각 저장 같은 별도 동의 절차는 만들지 않는다. 사용자가 로그인 화면 안내 방식을 골랐다.
- 만 14세 미만 법정대리인 동의 절차는 만들지 않는다. 사용자가 가입 제한을 골랐다.
- 백엔드는 바꾸지 않는다. 최신 `main`은 탈퇴할 때 소셜 로그인 토큰까지 이미 지운다.
