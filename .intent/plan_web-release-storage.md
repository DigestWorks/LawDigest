# 구현 및 배포

1. Python 표준 라이브러리로 릴리스 보관과 용량 점검 helper를 구현한다.
2. 기존 배포 스크립트의 의존성 설치 전 정리, 빌드 후 복사 전 용량 점검에 연결한다.
3. helper 변경의 웹 배포 감지를 추가하고, 임시 디렉터리에서 실행본·롤백본·심볼릭 링크 보호와 캐시 제외·공간 부족을 검사한다.
4. 운영 배포 경로의 기존 잠금과 절차를 유지하고 CI 이후 동일 경로로 배포한다. 운영 보관 상태와 복사 전 공간 점검 로그를 확인한다.

실패한 산출물이 여러 번 쌓여도 직전 정상 릴리스가 보존되도록 성공 시 previous 링크를 기록하고 정리에서 보호한다.
