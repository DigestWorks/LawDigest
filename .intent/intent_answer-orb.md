# AI 답변 구체 — 무지개에서 정당 분포로 물드는 오브

## 개발 목표와 의도

"AI 답변" 앞의 반짝임 표식을 AI 시스템에서 쓰는 빛나는 구체(glowing orb)로 바꾼다. 사용자의 말: "모두의입법의 무지개색 그러데이션 브랜딩 컬러를 적용하고, 검색이 끝나면 검색 결과의 정당 분포에 따라 정당색으로 물들도록 하자." "색상 섞어버리지 말고 다양한 색상이 오브 안에 공존하도록 하자."

## 기능 목록

| 기능 | 설명 | 왜 필요한가 |
|---|---|---|
| 무지개 구체 | 답을 만드는 동안 구체 안에서 무지개 시그니처 네 색이 각자 덩어리로 빠르게 돈다. | 검색 진입점과 같은 브랜드 색으로 AI가 일하는 중임을 보인다. |
| 정당 분포 구체 | 답이 끝나면 구체가 근거 법안 정당 분포대로 물든다. 건수가 많은 정당의 색 덩어리가 더 많고, 색은 섞이지 않고 공존한다. 이후 천천히 돈다. | 답이 어느 정당 의원들의 법안에 근거했는지 한눈에 보인다. |
| 반짝임 표식 제거 | 기존 반짝임 아이콘을 구체로 대체한다. | 같은 자리에 두 표식이 있을 이유가 없다. |

## 개발 목표

- 생성 중에는 무지개 구체가 돌고, 국민의힘 의원 검색이 끝나면 빨간 구체, '전세사기'처럼 섞인 검색이면 여러 정당색이 공존하는 구체가 된다.
- 동작 줄이기 설정에서는 돌지 않는다. 다크 모드에서도 구체 경계가 보인다.

## 범위 밖과 제약

- 공개 구현은 MIT 라이선스만 쓰고 저작권 고지를 남긴다(SmoothUI Siri Orb, react-ai-orb).
- 새 라이브러리를 더하지 않는다(CSS만).

## 변경 (2026-11-11)

구체가 작은 크기에서 탁하고 색이 과하다는 피드백("3D 구체보다 회전하는 링으로 만들어보는건 어떨까?")에 따라 회전하는 링으로 바꾼다.
- 생성 중: 검색창과 같은 무지개 원뿔형 링이 같은 속도로 돈다.
- 끝: 무지개가 돌며 흐려지고, 정당별 건수 비율 길이의 호(arc)로 나뉜 링이 제자리에 멈춘다. 색은 섞지 않는다.
- 외부 구체 코드는 쓰지 않는다(검색 링 CSS 재사용).
