# 2차 모두의입법 화면 복구

사용자가 로그인 상태를 유지하고 오류에서 복구하며 읽고 있는 정보의 출처와 시점을 확인할 수 있게 한다.

- 로그인 후 30분이 지나도 스크랩과 마이페이지를 계속 사용할 수 있게 한다. 세션 재발급과 개인화 상태가 어긋나 요청이 실패하거나 잘못된 성공 안내가 뜨는 일을 고친다.
- 로그인 실패·취소·만료를 이해할 수 있게 안내하고 원래 보던 화면으로 돌아갈 수 있게 한다. 불필요한 로그아웃과 화면 깜빡임을 줄인다.
- 계정 설정·알림·탈퇴에 도달할 수 있게 한다. 자신의 저장 정보와 계정을 직접 관리할 수 있어야 한다.
- 없는 주소에는 찾을 수 없는 화면을, 일시적 실패에는 재시도 수단을 제공한다. 내용 없는 목록과 로딩도 현재 화면의 맥락에서 보여 준다.
- 수집된 법안의 최신 발의일·타임라인의 최신 기록·원문 출처·AI 요약 표시를 제공한다. 수집 공백을 국회 활동이 없는 것으로 오해하지 않게 한다.
- 서비스 소개·자료 출처·계정 관련 문서로 가는 경로를 정리한다. 운영 주체·문의·보관 기준은 실제로 확정된 정보로 작성한다.

목표는 W7·W8·W9·W2의 결함을 현재 코드와 실제 화면에서 재현하고 고치는 것이다. 로그인 흐름은 실제 계정으로 재현한 뒤 수정하며 30분 뒤 재요청까지 확인한다. 정책의 필수 정보가 미정인 동안에는 문안을 검토용으로 보관하고 W8 완료 조건에 남긴다.

사용자의 ‘5단계까지 모든 intent 자동 수락’을 적용한다. 원래 handoff의 작업 순서와 범위를 유지한다. PR 머지·운영 DB 쓰기·timer 등록과 실제 계정 탈퇴는 각각 해당 실행의 승인을 받는다. 실제 모델·운영 인덱스 확인이 남은 RAG는 별도 PR #155에서 계속 검증한다.

계정 인증 전에 실패한 OAuth 응답이 허용된 웹 출처에만 복귀하도록 한다.
