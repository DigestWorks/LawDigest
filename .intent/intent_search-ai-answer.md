# 검색 결과 위 AI 답변과 에이전트 채팅

## 개발 목표와 의도

검색을 구글 AI 검색처럼 동작하게 한다. 사용자의 말: "검색바는 첫 턴에서 질문을 입력하는 거고, 첫 턴에 대한 답변이 생성되고, 그 아래 다음 채팅을 위한 채팅 바가 있고, 채팅 바에 다음 질문을 넣고 엔터를 누르면 에이전트 채팅 화면으로 진입. 채팅 바 아래에는 기존 검색 결과들이 있도록 함."

지금(cad70c7)은 검색바에서 키워드·의미 검색·AI 채팅 중 하나를 먼저 골라야 한다. AI 채팅을 고르면 `/ask`로 넘어가고, 그 화면은 제목·대수 토글·자료 건수·지연 경고·빈 화면 아이콘이 대화보다 먼저 보인다. 데스크톱에서는 질문을 화면 맨 위 헤더에서 쓰고 답은 아래에 쌓인다. 사용자는 이 디자인과 레이아웃이 마음에 들지 않는다고 했다.

## 기능 목록

| 기능 | 설명 | 왜 필요한가 |
|---|---|---|
| 검색 모드 선택 제거 | 검색바 아래의 키워드/의미 검색/AI 채팅 선택이 사라진다. 검색하면 늘 검색 결과 화면으로 간다. | 구글처럼 검색 한 번에 AI 답변과 검색 결과가 함께 나와야 하므로 고를 이유가 없다. |
| 검색 결과 맨 위 AI 답변 | 검색 결과 화면의 전체 탭 맨 위에 검색어에 대한 AI 답변이 생성된다. 생성 중에는 지금 하는 일(법안 검색, 원문 확인)이 한 줄로 보이고, 답이 길면 접혀 있다가 "더 보기"로 펼친다. 문단 끝 번호를 누르면 근거 법안으로 간다. | 첫 턴의 질문이 곧 검색어이므로, 결과를 훑기 전에 답부터 읽을 수 있어야 한다. |
| 답변 아래 채팅 바 | AI 답변 바로 아래에 무지개 테두리의 채팅 바가 있고, 그 아래로 기존 의원·정당·법안 검색 결과가 이어진다. | 첫 답을 읽고 바로 이어서 물을 자리가 필요하고, 검색 결과는 그대로 남아야 한다. |
| 에이전트 채팅 화면 | 채팅 바에 질문을 넣고 Enter를 누르면 `/ask`로 넘어간다. 첫 질문과 답이 위에 이어져 있고 새 질문의 답이 바로 생성된다. 질문은 제목처럼 크게, 답은 읽기 폭의 본문으로, 근거 법안은 검색 결과 줄과 같은 모양으로 보인다. 채팅 바는 화면 아래에 고정된다. | 후속 질문은 검색 결과가 아니라 대화 맥락에서 읽어야 한다. |
| 채팅 화면의 메타 문구 제거 | 자료 건수, 최신 발의일, 지연 경고 배너, 큰 제목과 설명을 지운다. 국외 이전 안내는 채팅 바 아래 한 줄로 줄인다. | 대화보다 안내가 먼저 보이고, 기준일·건수 문구는 콘텐츠 위에 두지 않기로 했다. |

## 개발 목표

- 헤더나 하단 바에서 "전세사기"를 검색하면 `/search/전세사기` 전체 탭 맨 위에 AI 답변이 생성되고, 그 아래 채팅 바, 그 아래 기존 검색 결과가 보인다.
- 채팅 바에 질문을 넣고 Enter를 누르면 `/ask`에서 첫 질문·답 아래로 새 답이 생성된다.
- `/ask`에서 뒤로 가면 검색 결과 화면의 AI 답변이 다시 생성되지 않고 그대로 보인다.
- 데스크톱과 모바일, 라이트와 다크 모드에서 같은 구조로 보인다.

## 범위 밖과 제약

- 답변 생성 백엔드(`services/ai`)와 `/api/qa/*` 계약은 바꾸지 않는다.
- 대화는 지금처럼 새로고침하면 사라진다. 저장하지 않는다.
- 검색은 모달 없이 제자리에서 펼친다는 기존 원칙을 지킨다.

## 열린 질문

없음. 모드 선택은 없애고, AI 답변은 모든 검색에서 자동으로 생성하기로 사용자가 답했다(2026-11-10).
