# 세션 재발급 구현 순서

1. AuthService에서 인증 실패를 Unauthorized로 전달하고 예상하지 못한 예외를 상위로 전달한다.
2. 웹 인터셉터에 재시도 표식과 공유 재발급 Promise를 둔다. OAuth 콜백의 HttpOnly 쿠키를 사용하도록 재발급은 API 호스트로 직접 요청한다. 라우터 훅을 사용하는 기존 성공 helper를 제거하고 실패 처리를 브라우저 이동으로 바꾼다.
3. 백엔드 실패·성공 계약과 웹 동시 요청·실패·재시도 응답을 검사한다.
4. 웹 빌드를 막는 기존 테스트 fixture의 필수 응답 필드와 타입에 맞지 않는 옵션을 정정한다.
5. 필수 CI 이후 배포하고 운영의 쿠키 없는 재발급 요청으로 HTTP 401을 확인한다. 실제 계정 검증 대기는 유지한다.
