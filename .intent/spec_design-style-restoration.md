# 디자인 복구 요구사항

기준은 DESIGN.md의 Buttons, Cards, Typography, 기존 FeedTab과 법안 피드다. shadcn 구조를 재사용하고 기본 테마의 그림자·각진 버튼이 제품에 섞이지 않도록 컴포넌트 변형에서 맞춘다.

타임라인은 연결된 날짜 축과 월·일 중심 제목, 유형별 제목 아래 반응형 카드 배열로 표현한다. 필터는 기존 시간순/인기처럼 pill 선택으로 표시한다. 전체 건수·첫 3건·20건씩 더 보기 및 키보드 초점 계약은 보존한다. 제목과 통계는 375px·중간 폭에서도 잘리지 않는다.

리포트는 새로운 화면이므로 원복 대상이 없다. 기존 피드 카드의 각진 외곽·얇은 구분·20px 제목과 26px 상세 제목, 메타·본문 구분을 따른다. 데이터 없는 미리보기나 정당 표식을 만들지 않는다. 보고서 경로와 본문 정제는 유지한다.

공통 버튼은 기본 pill, 그림자 없음, 투명한 보조 액션을 따른다. 아이콘 버튼·disabled·focus·asChild는 유지한다. 전역 색상 토큰이나 데이터 계약은 변경하지 않는다.
