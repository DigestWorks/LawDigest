# 인기 키워드 검색 연결

## 개발 목표와 의도

탐색 화면의 인기 키워드는 AI가 붙인 태그를 집계한다. 그런데 검색은 법안명과 요약 본문만 찾으므로, 본문에 그대로 쓰이지 않은 `쉬운우리말` 같은 키워드를 누르면 "일치하는 법안이 없습니다"가 나온다. 표시된 키워드를 누르면 항상 그 태그의 법안이 나오게 한다.

## 기능 목록

- 태그를 검색 문서에 넣는다. 사용자가 누른 키워드와 같은 말이 검색 대상에 있어야 법안을 찾을 수 있기 때문이다.
- 태그를 저장한 법안의 검색 문서를 바로 갱신한다. 정기 재빌드가 없어 새 요약과 태그가 검색에 반영되지 않기 때문이다.
- 지정한 법안만 검색 문서를 갱신하는 명령을 추가한다. 수동 백필한 법안은 기존 재빌드 대기열 29,441건에 밀려 반영이 늦어지기 때문이다.

## 개발 목표

- 인기 키워드 12개를 눌렀을 때 모두 법안이 한 건 이상 나온다.
- 검색 문서 갱신이 실패해도 이미 저장한 요약 실행을 실패로 만들지 않는다.
