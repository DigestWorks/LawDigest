# 구현 순서

1. 운영 API에서 분야·가결 불일치를 재현한다. 현재 코드에서 조회 범위와 UI 라벨을 확인한다.
2. 분야 집계 쿼리를 공유하고 목록 조건을 맞춘다. 타임라인과 탐색이 가결 집계를 공유하고 단계 수치의 이름을 맞춘다.
3. 결과값과 현직 의원·정당별 집계를 재현하고 보완한다. 격리 MySQL과 로컬 화면에서 범위·개수·사용자 표시를 확인한다.
4. 변경을 커밋하고 운영 적용 및 체크리스트 검증을 기존 handoff 순서에 맞춘다.
