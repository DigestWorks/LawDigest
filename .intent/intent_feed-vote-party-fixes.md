# 피드 기본 탭·표결 범례·국회 토글·정당 로고 정리

## 개발 목표와 의도

모두의입법 화면 다섯 곳의 어긋남을 고친다. 요청: "처음 사이트 접속 시 피드의 '법안'에서 시작. '법안', '리포트', '팔로잉' 순으로 정렬".
타임라인의 본회의 표결 카드에서 정당 로고·정당명·표 수가 옆 칸과 겹쳐 '1표'가 사회민주당 로고 위에 올라가 있었다.
탐색 › 국회의 '의원/정당' 토글은 선택 표시가 이동하지 않고 순간적으로 바뀌었다.
기본소득당·사회민주당 로고는 이미지 주소 환경 변수가 없는 환경에서 깨져 대체 텍스트가 원 밖으로 넘쳤다.
무소속은 정당이 아닌데 정당 목록 중간에 섞여 있었다.

## 기능 목록

| 기능 | 설명 | 왜 필요한가 |
|---|---|---|
| 피드 기본 탭 '법안' | 주소에 탭 지정 없이 홈에 들어오면 '법안' 탭이 열리고, 탭 순서가 법안·리포트·팔로잉이 된다 | 첫 화면에서 법안 목록을 바로 보여 달라는 요청이다 |
| 표결 정당 범례 겹침 수정 | 범례 칸이 카드 폭에 맞춰 늘고 줄며, 2열이 들어가면 2열, 아니면 1열로 바뀐다 | 고정 폭 칸이 좁은 카드에서 넘쳐 정당명·표 수가 서로 겹쳤다 |
| 의원/정당 토글 이동 애니메이션 | 탭을 누르면 검은 선택 표시가 옆 탭으로 미끄러져 이동한다 | 선택 표시가 순간 이동해 무엇이 바뀌었는지 눈으로 따라가기 어렵다 |
| 정당 로고 로컬화 | 사회민주당·기본소득당·새진보연합 로고를 웹 정적 파일로 제공하고, 마이페이지·팔로잉의 정당 로고도 같은 규칙을 따른다 | 이미지 주소 설정이 빠진 환경에서 로고가 깨지고, 다크 로고가 없는 정당은 다크 모드에서 깨졌다 |
| 무소속 맨 아래 | 탐색 정당 목록, 의석 분포 범례, 표결 정당 범례에서 무소속을 의석·표 수와 관계없이 마지막에 둔다 | 무소속은 정당이 아니므로 정당 순위 사이에 두면 안 된다 |

## 개발 목표

- 피드: `/`에 들어가면 '법안' 탭이 선택되어 있고 탭이 법안·리포트·팔로잉 순서다.
- 타임라인: 데스크톱 3열 카드에서 정당 범례가 2열로 겹침 없이 보인다.
- 탐색 › 국회: '정당'을 누르면 선택 표시가 왼쪽에서 오른쪽으로 이동한다.
- 로고: 로컬 개발 서버에서도 사회민주당·기본소득당 로고가 보인다.
- 정당 목록과 의석 분포 범례의 마지막 항목이 무소속이다.

## 범위 밖과 제약

- 소셜 로그인 '액세스 차단됨'은 공급자 콘솔의 Redirect URI 등록 문제로 코드 변경이 없다. 조치 방법은 채팅으로 안내한다.
- 피드 정렬 탭(시간순/인기)의 커서 애니메이션도 같은 원인으로 멈춰 있으나 HeroUI 업그레이드가 필요해 이번에 하지 않는다.
- 좌석도의 좌석 배치 순서는 목록이 아니므로 바꾸지 않는다.

## 열린 질문

- 375px 모바일 타임라인은 범례 폭이 267px라 1열이 된다. 2열을 원하면 표 수를 정당명 아래 줄로 내리는 구성 변경이 필요하다.
