# 법안 주제 태그 생성과 의원 사진 동기화

## 개발 목표와 의도

탐색 화면의 "지금 뜨는 키워드"가 나타나지 않는다. 운영 DB 43,653건 모두 `summary_tags`가 비어 있고, 현재 쓰는 Codex 요약 경로는 태그를 만들지 않는다. 사용자는 "AI 태그 생성 추가하고 백필은 지난 14일 범위까지만"을 선택했다.

의원 사진은 저장소에 수집 코드가 없어 새 의원이 들어와도 사진이 올라가지 않았다. 손솔 의원을 포함한 21명의 프로필에서 이름 첫 글자만 보였다. 21건은 이미 올렸고, 같은 일이 생기면 다시 채울 도구가 필요하다.

## 기능 목록

| 기능 | 설명 | 왜 필요한가 |
|---|---|---|
| 태그 생성 단계 | 요약이 있고 태그가 없는 최근 14일 법안에 주제어를 최대 5개 붙인다. | 키워드 집계의 원천 데이터가 없다. |
| 태그 검증 | 2~10자 단일 명사만 저장하고 중복과 일반어를 버린다. | 검색은 2자 미만을 거부하고, 표현이 흩어지면 집계가 되지 않는다. |
| 14일 백필 명령 | dry-run으로 결과를 본 뒤 `--execute`로 저장한다. | 이미 요약된 법안은 요약 경로가 다시 처리하지 않는다. |
| 사진 동기화 스크립트 | 버킷에 없는 사진을 국회 공식 경로에서 받아 덮어쓰기 없이 올린다. | 새 의원의 사진 누락을 다시 채울 수단이 없다. |

## 개발 목표

- `GET /v1/bill/trending-keywords?size=12`가 태그를 반환하고 탐색 화면에 키워드가 보인다.
- 키워드를 누르면 검색 결과 화면으로 이동한다.
- 백필은 최근 14일 법안만 바꾸고 요약 본문은 바꾸지 않는다.
- 사진 동기화 dry-run에서 누락 0건이 나온다.

## 범위 밖과 제약

- 정기 타이머 반영은 체크아웃과 승인 파일 교체가 필요해 사용자 승인 뒤에 진행한다.
- 집계 쿼리의 기간 제한은 이번 변경에 넣지 않는다.
