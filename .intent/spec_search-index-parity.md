법안명과 제목 일치, 원문 FULLTEXT 일치를 함께 조회하고 법안별로 중복을 제거한다. 정확히 일치한 이름·제목을 우선하고 부분 이름·제목, 원문 순서와 동률 정렬을 유지한다. 공개 법안만 대상으로 하며 검색어 검증과 원문의 토큰 검색 방식은 유지한다. 운영과 동일한 기본 MySQL 파서로 검증한다.

일곱 자리 의안번호와 제…호 표기는 공개 법안의 번호와 직접 대조한다. 번호 일치는 이름·원문 일치보다 먼저 나오고 검색 문서 유무에 좌우되지 않는다.
