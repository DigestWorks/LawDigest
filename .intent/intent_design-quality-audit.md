# 운영 화면 디자인 품질 결함 수정

## 개발 목표와 의도

운영 중인 `lawdigest.kr`을 데스크톱 1440px, 모바일 390px, 다크 모드로 점검했다. 요청은 "디자인 퀄리티가 낮은 부분, 디자인이 사람이 보기에 이상하거나 어색한 부분을 식별하고, 개선하도록 하자"이다.

의원 프로필에서 위원회 이름이 글자 단위로 끊긴 채 오른쪽으로 정렬되어 다섯 줄을 차지한다. 모바일 피드 제목은 "기관 간 통/보"처럼 낱말 중간에서 끊긴다. 법안 상세를 열어도 하단 내비게이션은 "피드"를 현재 위치로 표시한다.

이 작업은 재설계가 아니다. PR #242에서 복구한 기존 스타일과 `DESIGN.md`를 기준으로 눈에 보이는 결함만 고친다.

## 기능 목록

| 기능 | 설명 | 왜 필요한가 |
|---|---|---|
| 한국어 줄바꿈 | 낱말 경계에서 줄을 바꾸고, 제목의 줄 길이를 고르게 맞춘다 | 제목과 본문이 낱말 중간에서 끊겨 읽기 어렵다 |
| 접힌 요약 처리 | 접힌 요약의 끝을 서서히 흐리게 처리한다 | 글자가 가로로 잘린 채 표시된다 |
| 모바일 내비게이션 | 다섯 화면 밖에서는 활성 표시를 없애고 바탕을 더 불투명하게 한다 | 상세 화면에서 위치를 잘못 알려 주고, 뒤의 글자가 메뉴 글자와 겹쳐 보인다 |
| 헤더 동작 영역 | 테마 아이콘을 무채색으로 바꾸고 상세 화면에도 알림을 유지한다 | 파란 해 아이콘이 화면에서 가장 눈에 띄고, 화면마다 검색 아이콘 위치가 달라진다 |
| 의원 프로필 카드 | 사진과 이름을 왼쪽에 모으고 위원회를 한 줄씩 나열한다. 약력 토글에 이름을 붙인다 | 프로필에서 가장 어색한 영역이고, 이름 없는 화살표는 무엇을 여는지 알 수 없다 |
| 발의자 표시 | 이름 중복과 낱자 간격을 없애고, 사진 없는 의원은 이름 첫 글자로 표시하며, 빨간 배지를 무채색으로 바꾼다 | "손 솔"이 두 사람처럼 읽히고, 회색 원은 깨진 화면처럼 보인다. 빨간색은 오류 전용이다 |
| 법안 상세 패널 | 진행 단계를 왼쪽에 맞추고 중복된 STEP 표기를 지우며, 끊긴 세로선을 잇고 날짜 표기를 통일한다 | 패널 안에서 단계 목록만 다른 축에 있고, 같은 화면에 날짜 형식이 두 가지다 |
| 타임라인 디자인 복구 | Codex가 카드 그리드로 바꾼 화면을 `48c52a4`의 카드 넘김, 전체 보기 모달, 축 위 정당 표식, 상단 요약 카드로 되돌린다. 이후 추가된 단계 필터, 오류 재시도, 본회의 결과 묶음, 위원회별 모달, 제목 대체, 정당 없는 법안 처리는 유지한다 | 기존 디자인의 완성도가 더 높았고 Codex가 임의로 바꿨다(사용자 지시, 2026-11-07) |
| 탐색 빈 상태 | 인기 키워드가 없으면 영역을 숨긴다 | 첫 화면 최상단이 "없습니다" 상자로 시작한다 |
| 분야 화면 여백 | 법안 카드의 왼쪽 여백 중복을 없앤다 | 제목과 카드의 왼쪽 선이 어긋난다 |
| 소개·로그인·푸터 | 소개의 버튼 폭, 로그인 로고 간격, 푸터 왼쪽 선을 맞춘다 | 버튼이 840px로 늘어나고, 로고가 버튼에 붙고, 푸터만 다른 축에 있다 |
| 자료 기준일·출처 안내 제거 | 피드, 타임라인, 탐색, 분야, 법안 상세, 의원, 정당 화면 위의 기준일·요약 대기·출처 문구를 지운다. 서비스 소개에는 남긴다 | 콘텐츠보다 먼저 보이는 군더더기다(사용자 지시, 2026-11-06) |
| 대수 선택 드롭다운 | 피드의 제22대·제21대·전체 대수 버튼을 pill 드롭다운으로 바꿔 정렬 줄 오른쪽에 둔다 | 선택 컨트롤이 세 줄로 쌓여 법안이 아래로 밀린다(사용자 지시, 2026-11-06) |
| 평평한 표면 | 정보 카드와 프로필 표식의 그림자를 없앤다 | `DESIGN.md`의 Flat Trust Rule을 어긴다 |

## 개발 목표

- 390px에서 모든 점검 화면의 `scrollWidth`가 390이고, 제목이 낱말 중간에서 끊기지 않는다.
- 의원 프로필에서 위원회 이름을 한 줄에 하나씩 읽을 수 있다.
- 모바일에서 `/bill`, `/congressman`, `/party`, `/search`, `/login`에 활성 탭 표시가 없다.
- 타임라인이 `48c52a4`의 구성으로 보이고, 필터와 전체 목록 모달이 동작한다.
- 린트, 테스트, 프로덕션 빌드를 통과한다.

## 범위 밖

- 로고 형태 변경. 무지개 선이 글자를 가로지르는 문제는 브랜드 결정이므로 사용자에게 따로 묻는다.
- 정당색 요약 강조. 사용자가 승인한 표현이다(2026-11-03).
- 검색 모달 구조, 피드 카드 구조.
