# 법안 검색 문서 정기 갱신

## 개발 목표와 의도

검색은 법안 원본이 아니라 별도의 검색 문서를 읽는다. 이 문서를 정기적으로 다시 만드는 작업이 없어, 요약과 제목을 고쳐도 검색에 반영되지 않는 법안이 1,861건 있다. 새 변경이 빠르게 검색에 반영되고 과거 누락도 정리되게 한다.

## 기능 목록

- 갱신 대상을 최신 변경부터 처리한다. 지금은 오래된 순서라 대기 29,441건을 지나기 전에는 새 법안 차례가 오지 않기 때문이다.
- 대량 갱신을 200건마다 커밋한다. 전체를 한 트랜잭션으로 처리하면 법안 행 잠금이 길어져 다른 작업을 막기 때문이다.
- 매일 09:00 검색 문서 갱신 작업을 추가한다. 요약, 분야, 단계 변경이 끝난 뒤 반영해야 하기 때문이다.

## 개발 목표

- 평시 변경량 하루 100~230건을 하루 1,000건 한도 안에서 처리한다.
- 전체 재생성 1회 뒤 내용이 다른 문서가 0건이 된다.
