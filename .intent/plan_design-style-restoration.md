# 구현과 확인

1. 운영 타임라인·리포트 스크린샷과 현재 코드 및 48c52a4 비교로 재현했다. 기존 날짜 축·카드 배열을 단순 행 목록으로 교체한 흔적과 새 버튼의 rounded-md·shadow 기본값을 확인했다.
2. 공통 button/toggle 변형, 타임라인 ListContainer/TimelineEntries/TimelineBoard, 리포트 목록·상세를 수정한다. 신규 소개·질문 화면의 표면과 제목도 같은 기존 기준으로 맞춘다.
3. 웹 린트·기존 테스트·빌드를 한 번 실행한다. 새 클래스 나열만 확인하는 테스트는 추가하지 않는다. 기존 타임라인 키보드 더 보기 테스트를 유지한다.
4. 실제 로컬 화면을 데스크톱·375px·다크에서 확인한다. 커밋·푸시·PR·필수 CI 뒤 main에 병합하고 공식 배포 경로의 운영 결과를 확인한다.
