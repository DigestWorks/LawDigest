# 모두의입법 기존 디자인 복구

제가 추가한 타임라인·리포트·공통 버튼이 기존 화면의 디자인을 충분히 반영하지 못했다. 기존 DESIGN.md와 48c52a4의 실제 구성요소를 기준으로 맞춘다.

- 타임라인의 날짜 축·큰 날짜·얇은 구분선·법안 카드 배열을 복구한다.
- 신규 리포트 목록·상세와 서비스 소개에 기존 피드의 각진 표면·제목 위계·여백을 적용한다.
- 새 공통 버튼과 선택 컨트롤을 기존 pill 형태·무채색·약한 경계선으로 맞춘다.
- 최신 데이터, 단계 분류, 키보드 초점 이동, 더 보기, 접근성을 유지한다.

사용자가 5단계까지 intent를 자동 수락했고 이번 디자인 수정도 직접 지시했다. 별도 수락 질문을 반복하지 않는다. Expresso 인증서 후속은 Expresso #168에서 추적한다.
