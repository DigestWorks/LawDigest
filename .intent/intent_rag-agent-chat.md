# RAG 검색과 에이전틱 채팅

## 개발 목표와 의도
관심 주제를 자연어로 검색하고, 찾은 법안의 내용을 후속 질문으로 확인한다. 기존 원문 검증과 출처 표시를 보존하면서 Expresso의 도구 실행·취소·상태 표시 구조를 적용한다.

## 기능과 이유
- 검색 모드: 답변 생성을 기다리지 않고 관련 법안과 원문을 확인한다.
- 에이전틱 채팅: 모델이 필요한 검색어와 원문 조회를 선택하여 복합 질문과 비교에 필요한 근거를 모은다.
- 실행 상태와 중지: 현재 수행 중인 작업을 확인하고 불필요한 모델 실행을 멈춘다.
- 근거 연결: 답변 문단에서 실제 조회한 법안으로 이동한다.

## 개발 목표
검색과 채팅을 /ask에서 선택할 수 있고, 실패·근거 부족·취소가 구별되며 기존 질의응답 계약이 유지된다.

## 후속 요구 (2026-11-10)
실제 법안 데이터로 사용 가능하게 연결하고 최신 제자리 확장 검색바를 공통 입력으로 사용한다. 검색 화면과 채팅 화면의 입력이 분리되어 생기는 중복을 없앤다.
