공식 발의자 화면에 있는 의원이 현직 명부에서 매칭되지 않을 때, 법안의 명시된 대수와 공식 명단의 이름·한자명이 모두 일치하는 역대 의원의 코드 하나를 사용한다. 누락·동명이인·잘린 API 응답이면 해당 법안을 기존처럼 재시도 대상으로 남긴다. 해당 경로는 관계 확인에만 쓰며 의원 프로필·현직 명부를 변경하지 않는다.

발의자 행의 PPSR_ROLE이 발의자이면 NASS_CD를 공식 의원 코드로 사용한다. 대표발의는 기존 역할 필드의 명시값을 따른다. 유효한 코드나 대표발의자가 없으면 기존 보완 경로를 사용한다.
